Overview

Frontend markup translation for the server stream.

Five concerns, all string-in/string-out:

* +fb_to_sf+  - normalizes a client line on the way upstream
* +sf_to_wiz+ - rewrites a StormFront/XML line into the GSL escape
              vocabulary an old Wizard frontend understands
* +strip_xml+ - removes markup entirely, for scripts that want text
* +monsterbold_*+ - the emphasis pair for whatever frontend is attached
* +strip_game_links+ / +collapse_double_bold+ - give a front end that
              predates them DragonRealms' legacy line shape

Lifted out of global_defs.rb, where it could not be unit-tested: that file cannot be required from a spec without redefining the whole script-facing DSL (respond, get, put...) against production game infrastructure. The six global wrappers remain in global_defs.rb and delegate here, because scripts in the wild call them unqualified.

State note: sf_to_wiz and strip_xml both carry unterminated markup across calls, because a pushStream element can be split over two reads. Those buffers stay in the process-globals they have always lived in ($sftowiz_multiline, $strip_xml_multiline) rather than becoming module state -- games.rb clears $strip_xml_multiline directly on reconnect (see games.rb:435), and that remains a supported reach-in.

.collapse_double_bold(line) ⇒ String

Collapses the doubled bold the game puts around a linked creature (a <a ...>moradu) to the single pair of DragonRealms' legacy line. Front ends that keep bold as a flag, or match creatures with one pushBold/popBold pair (Genie's monster count, Frostbite's bold creature list), need it.

It runs after the downstream hooks and collapses pushes and pops separately, so it trusts a hook that adds bold not to make a new double: a hook right before a single game , with its elsewhere, leaves one push and two pops.

    one server string on its way to the client

    the line, or the same object when it has no doubled bold

def collapse_double_bold(line)
  return line unless line.include?(DOUBLE_PUSH_BOLD) || line.include?(DOUBLE_POP_BOLD)

  line.gsub(DOUBLE_PUSH_BOLD, '<pushBold/>').gsub(DOUBLE_POP_BOLD, '<popBold/>')
end

def fb_to_sf(line)
  return line if line == "\r\n"

  line = line.gsub(/<c>/, "")
  return nil if line.gsub("\r\n", '').length < 1

  line
rescue StandardError
  report_error('fb_to_sf', line)
  nil
end

def sf_to_wiz(line, bypass_multiline: false)
  return line if line == "\r\n"

  unless bypass_multiline
    line = buffer_sf_multiline(line)
    return nil if line.nil?
  end

  line = translate_launch_url(line)
  line = translate_speech(line)
  line = translate_thoughts(line)
  line = translate_voln(line)
  line = translate_familiar(line)
  line = translate_death(line)
  line = translate_room(line)
  line = translate_bold(line)

  line = line.gsub(SUPPRESSED_STREAMS, '')
  line = line.gsub(SPELLS_STREAM, '')
  line = line.gsub(DATA_ELEMENTS, '')
  line = line.gsub(ANY_TAG, '')
  line = line.gsub('&gt;', '>').gsub('&lt;', '<').gsub('&amp;', '&')
  return nil if line.gsub("\r\n", '').length < 1

  line
rescue StandardError
  report_error('sf_to_wiz', line)
  nil
end

.strip_game_links(line) ⇒ String

Removes the game's object links, keeping their text, so a front end that predates them gets DragonRealms' legacy line:

Also here: Universalist <a exist="-10700003" noun="Corwin">Corwin</a>.
Also here: Universalist Corwin.

Only elements with an exist attribute are game links; any other (a script's from a downstream hook) and its stay. Each closes the innermost still open in the string. A with none open is kept; the game sends every link whole within one string (none of the 2 million links in a day of DR logs spans two).

def strip_game_links(line)
  return line unless line.include?('<a') && line.match?(GAME_LINK)

  open_links = []
  line.gsub(LINK_TAG) do |tag|
    if tag == '</a>'
      open_links.pop ? '' : tag
    else
      game_link = tag.match?(GAME_LINK)
      open_links << game_link
      game_link ? '' : tag
    end
  end
end

.strip_link_bold(line) ⇒ String

Removes the single bold the game puts around a linked creature outside room-object listings, so a front end that predates it gets DragonRealms' legacy line, where those names are plain:

The <pushBold/><a exist="1" noun="moradu">jeol moradu</a><popBold/> moves into a position to parry.
The <a exist="1" noun="moradu">jeol moradu</a> moves into a position to parry.
<d cmd='look #1'><pushBold/>a <a exist="1" noun="moradu">jeol moradu</a><popBold/></d>
<d cmd='look #1'>a <a exist="1" noun="moradu">jeol moradu</a></d>

Only a pair around nothing but an optional article (a, an, the) and one game link goes. Room-object listings double their bold (collapse_double_bold keeps one pair there, as the legacy stream did), and a bold line or phrase with more text in it, such as a combat damage line, keeps its bold. Run it before strip_game_links, which removes the link it keys on.

It tells a listing from an action line only by that doubling, which every captured listing has (0 single pairs in room objs). If the game ever sends a listing with single bold, this strips it too, in all three places a listing reaches it: the room objs component, the block's , and the roomDesc line RoomBlock builds from it. The parser already accepts single bold there; this would then need to skip those spans by structure.

    one server string on its way to the client

  • (String) —

    the line, or the same object when it has no such bold
