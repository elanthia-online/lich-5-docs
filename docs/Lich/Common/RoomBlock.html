Overview

The Saga-identity stream (Frontend::CLIENT_STRING since #1700) renders a room in the main window as one inline element:

<room><name>[Area, Title] (230008)</name><description>...</description>
<exists>You also see ...</exists><crtrStatus .../><players>Also here: ...</players>
<exits>Obvious paths: <d>north</d>.</exits><extra></extra></room>

where the legacy stream (front ends sending their own Wrayth handshake) sends the roomName style, the roomDesc preset and one line per part. The rewrite targets that legacy layout; how the Saga client itself draws the block was not checked. The room components (room desc/objs/players/exits) are sent in both dialects and stay the parser's source of room state.

def compass(exits)
  dirs = exits.filter_map { |exit| %(<dir value="#{COMPASS_DIRS[exit]}"/>) if COMPASS_DIRS.key?(exit) }
  "<compass>#{dirs.join}</compass>"
end
