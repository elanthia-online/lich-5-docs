MUTATING_METHODS =

Core Ruby methods that change a Hash or an Array in place. A call to one of them through a proxy is applied to this session's copy and then replayed on the row as stored (Settings.save_proxy_changes), so that what other sessions saved in the same container is kept. Their blocks (delete_if { ... }) therefore run once on this session's copy and again on the stored container, and once more each time another session's write makes the save start over, so they must not have side effects. Both runs hold the lock of the script's settings in that scope (see Settings.with_proxy_lock), so a slow block delays the script's other threads writing settings in that scope until it returns.

  :<<, :[]=, :append, :clear, :collect!, :compact!, :compare_by_identity,

Constructor Details

#initialize(settings_module, scope, path, target, detached: false, script_name: nil, source: nil, unlocated: false, refusals: nil, copy: false, path_classes: nil, pathless_cause: nil, foreign_values: false, anchor: nil) ⇒ SettingsProxy

Minimal change: add detached flag (default false) Added script_name parameter to support InstanceSettings (core Lich functionality that runs outside of Script context). When script_name is provided, it takes precedence over Script.current.name in the save path.

source, for a detached view (what select or sort returned), is the container the view was taken from, so that an element taken from the view (view.first) can be found in it and saved where it is.

unlocated marks a proxy (detached, without a path) for an element of a view that can't be found in the settings: a write through it is refused with a message instead of being saved somewhere else.

refusals, shared by the container elements one call to #each yields and every container taken from them ([], dig, fetch, find, first, and the copies and views built from them, at any depth), counts the writes through them that were refused while the loop runs, so that the user is told once per loop for each kind of reason (see #refusals and Settings.refuse_proxy_save).

copy marks a new container built from an element #each yielded (row.merge(..), row.select { ... }, row.first(2)): like a plain Hash's, it is not part of the settings, so a write to it is refused with a message; its elements are found where the settings hold them (+source+ is that element's container). It is the method that built it (see #copied_by), or true.

path_classes (see #path_classes) defaults, for a path of at most one segment, to the root's class (a Hash), and otherwise to nil.

pathless_cause (see #pathless_cause) says, for a detached proxy without a path, what it is.

foreign_values marks a view taken from a container that may hold, at a key, a value that is not its source's (see #may_hold_foreign_values?): its elements are found in the source by identity only (see #source_segment).

anchor (see #moved?) is, for a container element #each yielded and every container taken from it, a list with one entry for each loop, outermost first, that yielded it or a container it is in: [the container of this session's copy that held the element, its key or index there, the element, the element's path].

def initialize(settings_module, scope, path, target, detached: false, script_name: nil, source: nil, unlocated: false, refusals: nil, copy: false,
               path_classes: nil, pathless_cause: nil, foreign_values: false, anchor: nil)
  @settings_module = settings_module # This should be the Settings module itself
  @scope  = scope
  @path   = path.dup
  @target = target
  @detached = detached
  @script_name = script_name
  @source = source
  @unlocated = unlocated
  @refusals = refusals

Delegates method calls to the target, handling both non-destructive and destructive methods.

Non-destructive methods return new containers, optionally tagged as detached views. Destructive methods are replayed on the stored row to preserve concurrent changes from other sessions. Detached views are automatically reattached to live containers before mutating operations.

def method_missing(method, *args, &block)
  @settings_module._log(Settings::LOG_LEVEL_DEBUG, LOG_PREFIX, -> { "CALL scope: #{@scope.inspect}, path: #{@path.inspect}, method: #{method}, args: #{args.inspect}, target_object_id: #{@target.object_id}" })
  if @target.respond_to?(method)
    if NON_DESTRUCTIVE_METHODS.include?(method)
      @settings_module._log(Settings::LOG_LEVEL_DEBUG, LOG_PREFIX, -> { "CALL   non-destructive method: #{method}" })
      target_dup = @target.dup
      unwrapped_args = args.map { |arg| arg.is_a?(SettingsProxy) ? @settings_module.unwrap_proxies(arg) : arg } # Corrected
      result = target_dup.send(method, *unwrapped_args, &block)
      # Minimal change: pass method name so we can tag views as detached and keep path
      return handle_non_destructive_result(method, result, unwrapped_args)
    else
      @settings_module._log(Settings::LOG_LEVEL_DEBUG, LOG_PREFIX, -> { "CALL   destructive method: #{method}" })

      # NEW (5.12.7+): auto-reattach derived views before mutating
      # ensure destructive methods (.push) do not target a proxy non-destructive method (.sort)
      #
      # The view is bound to the container at its path, as the stored
      # row holds it (Settings._reattach_live!), and the call is made on
      # that container and stored there. When there is none of the
      # view's kind, nothing is changed or stored, the user is told,
      # and the call returns nil.
      #
      # A detached proxy without a path (a view's element not found in
      # the settings, a view of a root proxy, the default fetch
      # returned, or a container built from one) is never reattached:
      # with an empty path that would bind it to the whole row. The
      # call runs on its copy, and the save that follows stores nothing
      # and tells the user (Settings.save_proxy_changes).
      if detached? && !@path.empty?
        unless @settings_module._reattach_live!(self, method)
          @settings_module._log(Settings::LOG_LEVEL_ERROR, LOG_PREFIX, -> { "CALL   reattach failed; aborting destructive op #{method} on detached view" })
          return nil
        end
      end

      unwrapped_args = args.map { |arg| arg.is_a?(SettingsProxy) ? @settings_module.unwrap_proxies(arg) : arg } # Corrected
      return call_mutating_method(method, unwrapped_args, block) if MUTATING_METHODS.include?(method)

      # Any other method (key?, each_pair, ...) may or may not change the
      # container. What it changed, if anything, is saved.
      before = dump_of_target
      known = own_containers
      result = @target.send(method, *unwrapped_args, &block)
      save_changes_since(method, before, known) if before.nil? || dump_of_target != before
      return handle_method_result(result, method, unwrapped_args)
    end
  else
    super
  end
end

def [](key)
  @settings_module._log(Settings::LOG_LEVEL_DEBUG, LOG_PREFIX, -> { "GET scope: #{@scope.inspect}, path: #{@path.inspect}, key: #{key.inspect}, target_object_id: #{@target.object_id}" })
  value = @target[key]
  if @settings_module.container?(value)
    # In a detached view (what select or sort returned), or a container
    # built from another one (#built_from_source?), a position is not
    # the element's position in the settings, so the element is looked
    # up in the container it was taken from. A negative Array index is
    # made positive, as for at and dig.
    (built_from_source? && view_element_proxy([key], value)) ||
      proxy_at(@path + (segment_in(@target, key) || [key]), value)
  else
    value
  end
end

def []=(key, value)
  @settings_module._log(Settings::LOG_LEVEL_DEBUG, LOG_PREFIX, -> { "SET scope: #{@scope.inspect}, path: #{@path.inspect}, key: #{key.inspect}, value: #{value.inspect}, target_object_id: #{@target.object_id}" })

Yields each element as Array#each and Hash#each do, a container element as a proxy with that element's path, so that a write through it (rows.each { |row| row = 1 }) is stored at that element, as for rows or rows.find { ... }. A Hash yields one [key, value] Array per entry, value proxied, which a |key, value| block takes apart, exactly as Hash#each's own blocks do.

For a detached view (what select or sort returned), or another container built from one (what reverse, last(2) or list - x returned), an element is proxied with the path it has in the container it was taken from (see #view_element_proxy); a [key, value] pair of a Hash (what sort_by returned for a Hash) is yielded as the Hash yields it, with its value proxied at that key. One the settings don't hold (an element of what map returned) is yielded detached and unlocated, so a write through it is refused, and the user is told once per loop (see #refusals).

def handle_non_destructive_result(method, result, args = [])
  @settings_module.reset_path_and_return(
    if @settings_module.container?(result) && built_from_source? && (element = view_element_proxy(keys_for(method, args), result))
      element
    elsif @settings_module.container?(result) && (element_path = element_path_for(method, args, result))
      proxy_at(element_path, result)
    elsif @settings_module.container?(result) && (pathless_element? || fetch_default?(method, args))
      pathless_derived_proxy(result, fetch_default?(method, args) ? "the default fetch returned" : nil)
    elsif @settings_module.container?(result) && yielded?
      SettingsProxy.new(@settings_module, @scope, @path.dup, result, script_name: @script_name, source: view_source, refusals: @refusals, copy: method,
                                                                       path_classes: @path_classes, anchor: @anchor)
    elsif @settings_module.container?(result)
      if @target.is_a?(Array) && [:find, :detect].include?(method)
        # For Array#find / Array#detect, identify the element index in the
        # original array and create a proxy that points to that element.
        idx = @target.index(result)

        if !idx.nil?
          element_path = @path.dup
          element_path << idx
          proxy_at(element_path, result)
        else
          # Fallback: if we somehow can't locate the element, preserve
          # the old behavior (path == @path, no index).
          is_view = NON_DESTRUCTIVE_CONTAINER_VIEWS.include?(method)
          SettingsProxy.new(@settings_module, @scope, @path.dup, result, detached: is_view, script_name: @script_name,
                                                                           path_classes: @path_classes, pathless_cause: view_cause(is_view))
        end
      else
        # Existing behavior for all other non-destructive container
        # methods. Every such container keeps the container it was
        # built from as its source, so that its elements are found
        # where the settings hold them (see #built_from_source?).
        is_view = NON_DESTRUCTIVE_CONTAINER_VIEWS.include?(method)
        SettingsProxy.new(@settings_module, @scope, @path.dup, result, detached: is_view, script_name: @script_name,
                                                                         source: view_source,
                                                                         path_classes: @path_classes, pathless_cause: view_cause(is_view),
                                                                         foreign_values: may_hold_foreign_values?, anchor: @anchor)
      end
    else
      # Non-container results (e.g., Hash#keys) stay as plain values
      result
    end
  )
end
