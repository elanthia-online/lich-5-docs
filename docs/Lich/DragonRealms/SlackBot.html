Overview

Slack API client for sending direct messages via DragonRealms LNet.

Caches the Slack users list in a shared SQLite store (DB_Store) with a 1-hour TTL. The cache is kept per token, so characters on the same game instance that use the same token share one cached copy, and a character never reads another workspace's users. Entries are never deleted: DB_Store has no delete and the TTL is checked on read, so lich.db keeps one row per token ever used. Randomized startup jitter prevents thundering herd on simultaneous character logins.

SEND_REQUEST_BUDGET =

Hard cap, in seconds, on each Slack API step (token check, users.list) that #direct_message runs when it has to restore the connection. A message is often sent right before an emergency logout, so it must never wait out the full network or rate-limit backoff.

5
STARTUP_REQUEST_BUDGET =

Hard cap, in seconds, on each Slack API step (token check, users.list) while the bot starts. SlackBot.new runs on the calling script's thread, often before that script's own safety checks start, so startup must not wait out the full network or rate-limit backoff either. A bot that gives up here retries on the next message.

def direct_message(username, message)
  if username.nil? || username.to_s.strip.empty?
    Lich::Messaging.msg('bold', 'SlackBot: Cannot send message - no username provided. Check your slackbot_username setting.')
    return nil
  end

  restore_connection unless initialized?

  unless initialized?
    Lich::Messaging.msg('bold', 'SlackBot: Cannot send message - not connected. Will retry on next attempt.')
    return nil
  end

  dm_channel = get_dm_channel(username)
  dm_channel = get_dm_channel(username) if dm_channel.nil? && reload_users_cache(username)
  unless dm_channel
    Lich::Messaging.msg('bold', "SlackBot: Cannot send message - user '#{username}' not found in Slack workspace.")
    return nil
  end

  params = {
    'token'   => UserVars.slack_token,
    'channel' => dm_channel,
    'text'    => "#{checkname}: #{message}",
    'as_user' => 'true'
  }
  post('chat.postMessage', params)
rescue Error => e
  Lich.log "SlackBot: Failed to send Slack message to #{username}: #{e.message}"
  Lich::Messaging.msg('bold', "SlackBot: Failed to send Slack message to #{username}: #{e.message}")
  nil
end

def lnet_connected?
  return false unless defined?(LNet)
  return false unless LNet.server
  return false if LNet.server.closed?

  if LNet.respond_to?(:last_recv) && LNet.last_recv
    return false if (Time.now - LNet.last_recv) > LNET_ACTIVITY_TIMEOUT
  end

  true
rescue IOError, Errno::EBADF, Errno::EPIPE, NoMethodError
  false
end
