Overview

Tracks the current room state: NPCs, PCs, exits, objects, and player status.

Data is shared across all running scripts and updated by the script engine as room text is received from the game server. Arrays are frozen when appropriate (npcs, dead_npcs) to prevent script-to-script interference; mutable arrays (pcs, room_objs) are live references.

.unignored_npcs(ignored) ⇒ Array<String>

npcs without the creatures an ignore list names. Same shape as npcs (sorted nouns, duplicates repeated), so it replaces the DRRoom.npcs - ignored idiom.

An entry always removes every NPC whose noun equals it, as npcs - ignored does. When the Creature roster lists exactly the living creatures in npcs, an entry also removes the creatures it names by noun or by full name (CreatureInstance#matches?), so "spectral white leopard" skips that pet but not a wild leopard. While the roster and npcs disagree (a refresh in progress, a creature with no name yet, or a name with no noun), only the noun rule applies.

Parameters:

  • ignored (Array<String>, nil) —

    configured entries

Returns:

  • (Array<String>) —

    a new array

def self.unignored_npcs(ignored)
  ignored = Array(ignored).compact.map(&:to_s)
  by_noun = npcs - ignored
  return by_noun if by_noun.empty?

  pairs = room_creatures_with_nouns
  return by_noun unless pairs

  pairs.reject { |creature, noun| ignored.include?(noun) || ignored.any? { |entry| creature.matches?(entry) } }
       .map(&:last)
       .sort
end
