Overview

Treasure drops available on a creature template.

Tracks currency (coins/gems), loot boxes, corpse harvest items (skin), and equipment by category (magic items, armaments, transmogs).

Examples:

treasure = Treasure.new(coins: true, gems: false, blunt_required: true)
treasure.has_coins? #=> true
treasure.to_h #=> {coins: true, gems: false, ...}

def initialize(data = {})
  @data = {
    coins: false,
    gems: false,
    boxes: false,
    skin: nil,
    magic_items: nil,
    other: nil,
    armaments: nil,
    transmogs: nil,
    blunt_required: false
  }.merge(data)
end
