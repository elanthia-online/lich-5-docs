Overview

This module is part of a private API. You should avoid using this module if possible, as it may be removed or be changed in the future.

Unified interface for Player System Manager (PSM) skills in GemStone IV.

Provides centralized utilities for Combat Maneuvers, Shield Specializations, Feats, Warcries, Weapon Techniques, Armor Specializations, and Ascension abilities. Handles skill lookup, stamina cost validation, cooldown checks, and command generation.

PSM categories are defined in separate submodules, each loadable as a file under psms/: CMan, Shield, Feat, Weapon, Armor, Warcry, Ascension, and QStrike.

Examples:

Check if a combat maneuver can be used with current stamina

PSMS.assess("bullrush", "CMan", true)

Generate a technique command

PSMS.command("cman", "bullrush", GameObj.targets.first)

FAILURES_REGEXES =

A compiled regular expression used to match common failure messages across all PSM (Player System Manager) actions.

This constant combines several game-generated failure messages into a single Regexp using Regexp.union, allowing centralized pattern matching for detecting failed actions.

Useful for interpreting command results and handling expected failure states in scripting logic. Note that in most cases, the match on a failure message here is not considered an error, but rather that the command succeeded, but the action itself failed for some reason.

Examples:

if PSMS::FAILURES_REGEXES.match?(response)
  respond "Action failed: #{response}"
end

Returns:

  • (Regexp) —

    A union of common failure message patterns.

Regexp.union(
  /^And give yourself away!  Never!$/,
  /^You are unable to do that right now\.$/,
  /^You don't seem to be able to move to do that\.$/,
  /^Provoking a GameMaster is not such a good idea\.$/,
  /^You do not currently have a target\.$/,
  /^Your mind clouds with confusion and you glance around uncertainly\.$/,
  /^But your hands are full\!$/,
  /^You are still stunned\.$/,
  /^You lack the momentum to attempt another skill\.$/,
  /^You can't reach .+!$/,
  / attempting to .+ would be a rather awkward proposition\.$/,
)

.assess(name, type, costcheck = false, forcert_count: 0) ⇒ Boolean, Object

Assess the validity or cost of a given PSM (Player System Manager) skill.

This method checks if a named PSM skill exists in a given category (type), and either:

- Verifies if the character has enough stamina to use it (when `costcheck` is true),
- Or retrieves the rank of the skill from Infomon (when `costcheck` is false).

If the skill cannot be found, it logs an error and raises an exception to halt execution.

or the Infomon rank of the skill otherwise.

Examples:

Check if a combat maneuver can be used with current stamina

assess("feint", "CMan", true)

Get the Infomon rank of a shield technique

assess("bulwark", "Shield")

Check if a feat can be used with current stamina, considering forced RT applications

assess("shield bash", "Feat", true, forcert_count: 2)

Parameters:

  • name (String) —

    The name of the PSM skill to assess.

  • type (String) —

    The category of the PSM skill (e.g., "Armor", "CMan", "Feat", "Shield", "Warcry", "Weapon").

  • costcheck (Boolean) (defaults to: false) —

    If true, check whether the character has enough stamina to use the skill.

  • forcert_count (Integer) (defaults to: 0) —

    Optional. Number of forced RT applications, affecting stamina cost calculation (default: 0).

Returns:

  • (Boolean, Object) —

    Returns a boolean if costcheck is true (indicating stamina sufficiency),

Raises:

  • (StandardError) —

    If the skill name is invalid or not found in the given category.

def self.assess(name, type, costcheck = false, forcert_count: 0)
  return false unless forcert_count <= max_forcert_count
  name = self.name_normal(name)
  seek_psm = self.find_name(name, type) || invalid_technique!(name, type)
  if costcheck
    category = Object.const_get("Lich::Gemstone::#{type}")
    cost_affordable?(category.respond_to?(:cost) ? category.cost(name) : seek_psm[:cost], forcert_count: forcert_count)
  else
    Infomon.get("#{type.downcase}.#{seek_psm[:short_name]}")
  end
end

def self.command(verb, usage, target = "", forcert_count: 0)
  cmd = verb.nil? || verb.to_s.empty? ? usage.to_s : "#{verb} #{usage}"
  if target.is_a?(GameObj)
    cmd += " ##{target.id}"
  elsif target.is_a?(Integer)
    cmd += " ##{target}"
  elsif target.to_s != ""
    cmd += " #{target}"
  end
  cmd += " forcert" if forcert_count > 0
  cmd
end

def self.cost_affordable?(cost, forcert_count: 0)
  return false unless forcert_count <= max_forcert_count

  cost.all? do |cost_type, cost_amount|
    cost_amount = (cost_amount + (cost_amount * ((25 + (10.0 * forcert_count)) / 100))).truncate if forcert_count > 0
    cost_amount < XMLData.public_send(cost_type)
  end
end

.dispatch(usage_cmd, results_regex, timeout: 5) ⇒ String?

Sends a technique command and waits for its answer. dothistimeout itself waits out and re-sends after "...wait N seconds." def self.dispatch(usage_cmd, results_regex, timeout: 5)
  usage_result = dothistimeout(usage_cmd, timeout, results_regex)
  return usage_result unless usage_result == "You don't seem to be able to move to do that."

  recovered = false
  100.times do
    break if (recovered = clear.any? { |line| line =~ RECOVERED_REGEX })

    sleep 0.1
  end
  recovered ? dothistimeout(usage_cmd, timeout, results_regex) : usage_result
end

def self.effect_active?(registry, effect)
  now = Time.now.to_f
  wanted = effect.is_a?(Regexp) ? effect : name_normal(effect.to_s)
  # Iterate a snapshot: to_h is the parser's live Hash, which the game
  # thread clears and refills; adding a key mid-iteration raises in the parser.
  registry.to_h.dup.any? do |key, expiry|
    next false unless expiry.to_f > now

    wanted.is_a?(Regexp) ? wanted.match?(key.to_s) : name_normal(key.to_s) == wanted
  end
end

def self.find_name(name, type)

.max_forcert_count ⇒ Integer

Determines the maximum number of forced roundtime (forcert) activations allowed based on the character's Multi-Opponent Combat (MOC) training.

The number of forcert rounds scales with ranks in MOC as follows:

- 0-9 ranks:     0 forcert rounds
- 10-34 ranks:   1 forcert round
- 35-74 ranks:   2 forcert rounds
- 75-124 ranks:  3 forcert rounds
- 125+ ranks:    4 forcert rounds

Examples:

# => 3  (for a character with 100 MOC ranks)

def self.mstrike_available?(focused: false)
  return false if Skills.multi_opponent_combat < (focused ? 30 : 5)
  return false if effect_active?(Effects::Debuffs, 'Overexerted')

def self.results_regex(name, *patterns, results_of_interest: nil)
  parts = [FAILURES_REGEXES, /^#{name} what\?$/i, /^#{name} is still in cooldown\./i]
  parts.concat(patterns.compact)
  parts << results_of_interest if results_of_interest.is_a?(Regexp)
  Regexp.union(*parts)
end
