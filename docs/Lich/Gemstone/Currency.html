Overview

Access character currency holdings including silver, notes, and specialty scrips.

All accessor methods query Infomon's cached wealth data; use the refresh: parameter or explicit refresh methods to send WEALTH commands to the game server.

.refresh(all: false) ⇒ Integer?

Send WEALTH so Infomon re-reads the silver carried (WEALTH is quiet by default; LOUD is the option that echoes to the room). The response is parsed on the game thread before hooks run, so hiding it from the front end does not hide it from Infomon.

Parameters:

  • all (Boolean) (defaults to: false) —

    WEALTH ALL, which also refreshes gigas fragments, redsteel marks and gemstone dust

Returns:

  • (Integer, nil) —

    the refreshed silver

def self.refresh(all: false)
  Lich::Util.issue_command(all ? 'wealth all' : 'wealth', Lich::Gemstone::Infomon::Parser::Pattern::WealthSilver, silent: true, quiet: true)
  Lich::Gemstone::Infomon.get('currency.silver')
end
