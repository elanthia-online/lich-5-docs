Overview

Note:

Entries are stored as GameObj instances; ReadyList.valid? confirms all stored items remain in inventory, containers, or hands.

Tracks equipped items and storage locations from the "ready list" command in GemStone IV.

Maintains two parallel lists: a ready list of currently equipped items (shields, weapons, wands, etc.) and a store list of items staged for retrieval from storage. Use ReadyList.check to sync state from the game server, then read individual entries via accessor methods like weapon or store_weapon.

.check(silent: false, quiet: false) ⇒ void

This method returns an undefined value.

Syncs ready list state from the game server by parsing "ready list" command output.

Waits for roundtime, issues the "ready list" command, and reads equipment assignments from the server response. Parses the response to extract item IDs and slot types, populating ready_list and store_list. Sets checked? to true only if the response contains "Your current settings are:", indicating a valid ready list from the server.

def check(silent: false, quiet: false)
  if quiet
    start_pattern = /<output class="mono"\/>|^You are a ghost!/
  else
    start_pattern = /Your current settings are:|^You are a ghost!/
  end
  waitrt?
  results = Lich::Util.issue_command("ready list", start_pattern, silent: silent, quiet: quiet)
  @checked = results.any? { |line| line.match?(/Your current settings are:/) }
end

def reset(all: false)
  @checked = false
  @ready_list.each do |key, _value|
    next unless all || ORIGINAL_READY_LIST.include?(key)
    @ready_list[key] = nil
  end
  @store_list.each do |key, _value|
    next unless all || ORIGINAL_STORE_LIST.include?(key)
    @store_list[key] = nil
  end
end

.valid?(all: false) ⇒ Boolean

Verifies that all stored equipment items still exist in inventory, containers, or hands.

Confirms checked? is true, then iterates the ready list verifying each non-wand entry either has a nil value or the GameObj (by id) still appears in GameObj.inv, GameObj.containers, GameObj.right_hand, or GameObj.left_hand. Wand entries are excluded from validation. Sets checked= to false if any item is missing.

Examples:

Parameters:

  • all (Boolean) (defaults to: false) —

    if true, validate all ready_list entries; if false (default), validate only entries in ORIGINAL_READY_LIST

Returns:

  • (Boolean) —

    true if checked and all relevant items are valid; false if not checked or an item is missing

def valid?(all: false)
  # check if existing ready items are valid or not
  return false unless checked?
  @ready_list.each do |key, value|
    next unless all || ORIGINAL_READY_LIST.include?(key)
    unless key.eql?(:wand) || value.nil? || GameObj.inv.map(&:id).include?(value.id) || GameObj.containers.values.flatten.map(&:id).include?(value.id) || GameObj.right_hand.id.eql?(value.id) || GameObj.left_hand.id.eql?(value.id)
      @checked = false
      return false
    end
  end
  return true
end
