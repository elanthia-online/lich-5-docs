Overview

Reads and compiles player-supplied combat definitions from a YAML file at DATA_DIR/combat/defs.yaml.

Entries are compiled into the same Struct objects the shipped tables use, allowing them to be spliced into the assembly step and included in every derived lookup, detector, and PatternGate rebuild. The supplement file is re-read when its modification time changes, and reset! forces a re-read regardless. Reloads never touch shipped constants; with no file present every reader returns an empty frozen array.

Validation, timeout-bounded regex compilation, reporting, and memoization are shared with Lich::Common::UserDefs. One bad entry never disables the rest; every rejection names the kind, index, value, reason, and consequence.

.assembled!(kind) ⇒ void

This method returns an undefined value.

Records that one def module has just assembled its table from the current file, so stale? answers for the tables the parser matches against rather than for the document cache. Called by each def module at the point it splices the supplements in -- at require time and again on every reload, which are the only two ways a table is built. Inspecting a reader (loaded, summary) deliberately does not call it.

Recorded per kind, because reload_defs! reports a def file that fails to load and carries on with the rest: one shared stamp let the files that did reload answer for the one that did not, so stale? went false while that module's previous table was still live and the login check never retried it.

def assembled!(kind)
  # The stamp is the mtime the DOCUMENT was parsed at, not a fresh
  # stat: the caller's table was built from that document, and an
  # edit landing between its reader call and this line would
  # otherwise be recorded as assembled while the table is still
  # behind the file, and the login check would skip the reload.
  @assembled_mtimes[kind.to_sym] = @loaded_mtime
end

def loaded
  {
    attacks: ATTACK_SLOTS.to_h { |s| [s, attacks(s).map(&:name)] }.reject { |_slot, names| names.empty? },
    flares: flares.map(&:name),
    statuses: statuses.map(&:name),
    outcomes: outcomes.map(&:type),
    messages: memoize(:messages).transform_values { |rows| rows.map(&:first) }
  }.reject { |_kind, entries| entries.empty? }
end

def notify_reloaded(reloaded)
  combat = Lich::Gemstone::Combat
  combat::Messages.refresh! if combat.const_defined?(:Messages, false)
  Lich::Common::Events.emit('combat.definitions_reloaded',
                            { files: reloaded.map { |f| File.basename(f) }.freeze,
                              supplements: summary.freeze })
end

.reload_defs!(notify: true) ⇒ Array<String>

Re-reads the supplement file and re-executes every loaded def file so each rebinds its TABLE from shipped defs plus the current supplements. Equivalent to ;hmr combat/defs/ with Ruby's constant-redefinition warnings silenced. def reload_defs!(notify: true)
  reset!
  @lock.synchronize { @reported_payloads = [] }
  files = $LOADED_FEATURES.grep(DEF_FILE_PATTERN)
  reloaded = []
  verbose = $VERBOSE
  $VERBOSE = nil
  files.each do |file|
    load(file)
    reloaded << file
  rescue ScriptError, StandardError => e
    report("#{File.basename(file)} failed to reload: #{e.class}: #{e.message}. Its previous definitions remain in effect.")
  end
  $VERBOSE = verbose
  report_debug("reloaded #{reloaded.size} def files; supplements: #{summary}")
  notify_reloaded(reloaded) if notify
  reloaded
end

.stale? ⇒ Boolean

True when the file on disk (present or not) differs from what the current def tables were assembled from, so a reload_defs! would change something. Cheap: one stat.

Deliberately NOT the document cache's stamp (@loaded_mtime): reading a supplement re-parses the file, which every reader does, but only a def module rebuilds the table the parser matches against. Sharing one stamp let an inspection call -- loaded or summary, the very things a player runs after an edit -- answer "not stale" while the new definition was still unrecognised, and the login-time reload then skipped it.

True when ANY assembled kind is behind the file, so a reload in which one def file failed still reports stale and gets retried. Only the kinds that have assembled are compared: a kind whose module was never loaded has no table to be out of date, and counting it would report stale forever. Before any def module has loaded there is nothing to answer for, which reads as stale so a reload is not skipped; the one caller (Tracker, at login) runs long after they are required.

def stale?
  current = present? ? File.mtime(path) : nil
  return true if @assembled_mtimes.empty?

  @assembled_mtimes.each_value.any? { |stamp| stamp != current }
end
