Overview

Namespace for spell wear-off pattern definitions and parsing.

This module defines third-person wear-off lines for spell-circle spells, keyed by spell number. Patterns are pinned to spells via wiki documentation and cross-log timestamp pairing. The generic fallback pattern (spell: nil) covers unidentified spell expirations.

SPELL_LOSSES =

Array of spell loss definitions, mapping third-person wear-off patterns to spell identity (number and name).

Each entry is a SpellLossDef capturing:

  • spell: Integer or nil (nil for the generic fallback pattern)
  • spell_name: String descriptive spell name
  • patterns: Array of Regexp matching third-person wear-off lines

Patterns use named capture group :target to extract the affected character. The final entry with spell: nil is the game's generic wear-off ("appears somehow different", "seems slightly different") for spells without bespoke end messaging.

def self.parse(line)
  return nil if PatternGate.rejects?(GATE, ALWAYS_SCAN, line)

  LOOKUP.each do |pattern, loss_def|
    if (match = pattern.match(line))
      return {
        spell: loss_def.spell,
        spell_name: loss_def.spell_name,
        target: match[:target]
      }
    end
  end
  nil
end
