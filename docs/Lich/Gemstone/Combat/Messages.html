Overview

Combat message event dispatcher - matches game output to subscription events.

Messages are non-combat events delivered as combat. on the Events board, matched only while subscribed. A single worker thread processes game output lines through a message family matcher; subscribers run on that worker and must be cheap, non-blocking, and issue no game commands.

Installation is automatic: a hook is installed when the first subscription to a message event appears and removed with the last, gated by the matcher checking whether any subscriber exists for each event. With no subscribers, no hook runs.

Examples:

Subscribe to a disarm message event

Combat::Tracker.on(:disarm_seen) { |_type, data| queue << data }

Subscribe to multiple events

Combat::Tracker.on(:ambusher, :bolted, name: 'myscript') { |type, data| ... }

def process(line)
  found = scan(line)
  @scanned += 1
  @matched += found.size
  found.each { |event, data| Lich::Common::Events.emit("combat.#{event}", data) }
  found
end

.refresh! ⇒ Object

Recompute the active families from the subscriptions and put the hook up or take it down to match. Events calls this on every combat.* subscription change, and Supplements.reload_defs! after a reload (a script may subscribe to an event before the player's file defines it); harmless to call again.

The whole read-decide-act sequence is held under @mutex: two scripts subscribing at once would otherwise interleave so that the last @active write is non-empty while the last hook call is uninstall!, silently leaving a live subscriber with no hook.

DownstreamHook.add/remove raises (Events swallows and logs it), the previous consistent @active/@hook pair stays in place rather than reporting a family active with no hook up, or the reverse.

def refresh!
  @mutex.synchronize do
    active = families.select { |f| f.events.any? { |e| Lich::Common::Events.any_for?("combat.#{e}") } }.map(&:name).freeze
    active.empty? ? uninstall! : install!
    @active = active
    active_families
  end
end

def shutdown
  return unless @worker&.alive?

  @queue&.push(:shutdown)
  @worker.join(2)
  @worker = nil
end
